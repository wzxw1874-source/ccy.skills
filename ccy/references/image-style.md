# Image Prompt Preferences

## General Aesthetic

Prefer:

- simple
- high-quality
- powerful but not flashy
- clear subject
- stable composition
- natural lighting
- unified style
- restrained detail

Avoid:

- clutter
- random extra elements
- messy typography
- exaggerated expressions
- overfilled backgrounds
- changing the main subject when editing

## Character Image Editing

When the user asks to modify only an action or expression:

- preserve identity
- preserve face shape, hairstyle, clothing, body proportion
- preserve original art style, lighting, background, and camera angle
- only modify the requested pose, gesture, or expression
- do not add new people
- do not change clothing, hairstyle, color palette, or background
- make hands natural and anatomically plausible
- keep expressions restrained unless the user requests otherwise
- make the result feel like a natural edit of the original image

## Poster Or Wallpaper Prompts

Prefer:

- subject in the visual center
- enough negative space for horizontal wallpaper
- dark gray, black gray, misty, or soft gradient background only when appropriate
- subtle supporting silhouettes or shadows that do not steal focus
- refined, calm, strong visual tone

Avoid:

- calligraphy-like text unless requested
- over-commercial poster style
- filling every part of the image

## Reusable Edit Prompt Pattern

```text
请参考我提供的图片，只修改……，其他保持不变。
具体要求：主体保持原图中的身份、脸型、发型、服装、身体比例、画风、光影、背景和整体构图不变。
只让主体……；表情……；动作……。
不要改变……；不要新增……。
保持原图风格一致，像是在原图基础上自然修改。
```
