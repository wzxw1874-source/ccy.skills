# PPT Style Preferences

## Visual Style

Prefer:

- 16:9 horizontal slides
- white and light blue background
- dark blue large titles
- electric blue technology lines
- light blue gradients
- restrained glow effects
- bright, clean, academic technology style
- modern sans-serif type
- bold titles
- blue highlights for keywords
- simple edge-line decoration when useful
- centered formulas with clear spacing

Avoid:

- dark overall style
- complex backgrounds
- excessive decorative bars
- page numbers unless requested
- dense text blocks
- visually messy layouts
- over-commercial poster style

## Language

For English classroom presentations, use English unless the user explicitly asks for Chinese. Keep wording simple and presentation-friendly.

## Content Rules

- Preserve the main technical content.
- Use simple sentences.
- Give each slide one clear theme.
- Use diagrams that are simple and stylistically consistent.
- Do not stack too many elements on one page.

## Suggested Output For PPT Planning

When the user asks for a PPT plan or prompt, provide:

1. slide title
2. slide body
3. figure suggestion
4. layout notes
5. a complete prompt suitable for a PPT-generation tool, if requested
